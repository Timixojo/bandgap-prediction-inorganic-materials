# Bandgap Prediction for Inorganic Materials

Predicting the bandgap of inorganic materials using supervised machine learning algorithms.

## Overview

This repository contains a machine learning project that investigates the prediction of inorganic material bandgaps using supervised learning techniques. The project compares the performance of multiple regression models, including:

- Decision Tree Regression
- Random Forest Regression
- Support Vector Regression (SVR)
- XGBoost Regression

This project was developed as part of my MRes Artificial Intelligence programme at the University of Greater Manchester.
